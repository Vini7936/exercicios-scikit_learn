# Exercícios para praticar Scikit Learn
Nesse repositório estão os exercícios que usei para praticar machine learning com a biblioteca Scikit-Learn do Python. Para esses exercícios foram utilizados diversos tipos de algoritmos, incluindo de Naive Bayes e Árvore de Decisão para a realização de previsões. Também concluí a pratica de Seleção de Atributos e Aprendizado por Instância.
